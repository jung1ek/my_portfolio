I am not interested in wrapping an API and calling it research. The useful NLP projects, for me, are boring on purpose:

1. Pick a dataset small enough to read.
2. Train a baseline that is allowed to be dumb.
3. Change one thing.
4. Report the delta like an adult.

If the metric only moves when the seed changes, the project is done — you learned that the task was noisy.
